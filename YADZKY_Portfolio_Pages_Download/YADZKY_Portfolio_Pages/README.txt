YADZKY PORTFOLIO — READY-TO-FILL PROJECT PAGES

CARA PAKAI
1. Extract ZIP ini.
2. Copy project-01.html sampai project-05.html ke folder creative-portfolio, sejajar dengan index.html.
3. Copy folder assets ke folder creative-portfolio yang sama.
4. Kalau sudah punya gambar, masukkan ke folder assets dan gunakan nama file persis:
   project-01.jpg  = Graphic Design & Posters
   project-02.jpg  = Film & Video Production
   project-03.jpg  = Photography & Documentation
   project-04.jpg  = Social Media Specialist
   project-05.jpg  = Event Organization
5. Gambar belum ada? Tidak masalah. Halaman tetap menampilkan placeholder, bukan gambar rusak.
6. Buka index.html dan klik kartu Works untuk mengetes.

CATATAN
- Jangan hapus atau ubah nama file HTML.
- Untuk sekarang folder assets boleh kosong.
- Homepage index.html milikmu tidak disertakan agar editan homepage-mu tetap aman.
- Deskripsi project adalah template umum; sesuaikan setelah memasukkan karya asli.
