YADZKY — Project Detail Pages

Files included:
- project-01.html — Graphic Design & Posters
- project-02.html — Film & Video Production
- project-03.html — Photography & Documentation
- project-04.html — Social Media Specialist
- project-05.html — Event Organization

How to use:
1. Extract the ZIP.
2. Copy all five HTML files into the same folder as index.html.
3. Keep the filenames exactly as written, because your homepage links to these names.
4. Open index.html in your browser and click each Works card.
5. Replace the media placeholder and revise each project description when you have real assets ready.

These pages intentionally do not add descriptions back to the homepage cards. Project text is inside the individual detail pages.
